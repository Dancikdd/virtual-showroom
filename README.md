# virtual-showroom

**Virtual Showroom** este o aplicație web 3D interactivă care permite utilizatorilor să exploreze și să interacționeze cu obiecte într-un mediu virtual. Proiectul oferă navigare ușoară, animații și o prezentare modernă a produselor direct în browser.

## Tehnologii utilizate
- Three.js
- Vite
- JavaScript
- HTML / CSS

## Funcționalități
- Randare de obiecte 3D în browser
- Control al camerei (rotire, zoom, mișcare)
- Interacțiune cu obiectele din scenă
- Animații și efecte vizuale
- Încărcare modele 3D (ex: .glb)

## Scopul proiectului
Proiectul are scopul de a crea o experiență de tip showroom digital, unde produsele sau obiectele pot fi vizualizate într-un mod mai realist și interactiv decât în imaginile clasice 2D.

## Instalare și rulare
```bash
git clone https://github.com/Dancikdd/virtual-showroom
cd virtual-showroom
npm install
npm run dev
```
